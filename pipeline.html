🔄 Cơ chế Switch Live — atomic rename, không downtime

Không có flag riêng. "Live switch" chính là POSIX rename atomic + mmap re-open lazy của Open-Meteo binary.

1

Tải vào file tạm

Sync container ghi dữ liệu mới vào file ẩn, API không bao giờ đọc file .tmp.

data/gfs/T2m/chunk_143.om.tmp
2

Verify checksum

So khớp size + hash với manifest S3 trước khi commit.

✓ size · ✓ hash · ✓ readable
3

Atomic rename

POSIX rename(2) trên cùng filesystem là atomic — không có "half state".

rename(.tmp, chunk_143.om)
4

API re-open lazy

Request tiếp theo đụng chunk này → omfc-api mmap file mới. User cũ vẫn đọc xong run cũ an toàn.

user N: run cũ · user N+1: run mới

Hệ quả: không cần restart container · không có downtime · không có cờ phải toggle · độ trễ tối đa user thấy data mới = 60s (nginx cache TTL) sau moment rename.
